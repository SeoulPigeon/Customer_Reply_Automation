# 배포 구성의 상태

이 디렉터리는 **배포할 설정 파일**입니다. 아직 서버나 HTTPS 주소가 생성된 것은 아닙니다.
현재 선택한 구성은 단일 Linux 서버 + Caddy HTTPS + systemd + 로컬 영속 SQLite입니다.
실제 설치, 비밀정보 등록, 초기 관리자 생성, 복원 절차는 [배포 안내](../docs/DEPLOYMENT.md)를 따릅니다.

웹 프로세스 하나가 Gmail 수신과 예약 작업을 함께 수행합니다. `--workers 1`을 유지하고
별도의 스케줄러를 중복 실행하지 않습니다. 프로세스 내부 중복 실행 방지 외에도 SQLite
발송 예약 트랜잭션과 고유 outbox 기록을 유지합니다. 외부 Gmail 호출과 고객 답장 도착 사이의
시간차를 완전히 제거한다고 주장하지 않습니다.
